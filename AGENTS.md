# Kian project bootstrap

This repository uses the global **Kian Cinematic Web System** plugin when the task involves websites, frontend UI, animation, Three.js/WebGL, GSAP, performance, accessibility, responsive behavior, or visual QA.

- Read the repository before editing.
- Preserve unrelated work.
- Select relevant installed skills rather than loading all skills.
- For substantial website work, use Creative/Visual, 3D/Motion, Frontend/Systems, Performance/Accessibility, and Visual QA review passes.
- If real subagents are supported, delegate independent passes; otherwise perform the same roles sequentially.
- Run the project's actual build/tests before reporting success.
- Respect project-specific stack, deployment, language, content and business constraints.
